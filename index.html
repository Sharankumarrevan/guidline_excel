CLMS Excel Upload Guidelines

📋 Basic Formatting Instructions

Field Required Format Correct Example Incorrect Example
Date yyyy-mm-dd (Cell format must be TEXT) 2025-08-20 20/08/2025
Gender First letter should be capital Male, Female male, FEMALE
Status Status should be in this format Married,Unmarried married, un-married
Blood Group Use valid blood group format A+, B+, O-, AB+ A positive
Pincode Must contain exactly 6 digits 560001 56001
Aadhar Number Must contain exactly 12 digits and should be unique 123456789012 12345
Contractor Code Only alphanumeric values allowed. Special characters allowed: "_" and "-" CNT_001 CNT@001

⚠️ Mandatory Contractor Details

Important:

All red-marked fields in the Excel sheet are mandatory and must be filled carefully while uploading contractor details.

  • CLMS: Refer to EXCEL_DOWNLOAD_TEMPLATE from EXCEL_UPLOAD.
  • HRIS: Refer to EXCEL_DOWNLOAD_TEMPLATE from EXCEL_UPLOAD.

📌 Important Notes

  • Ensure all mandatory fields are filled before upload.
  • Avoid duplicate Aadhar numbers.
  • Do not use unsupported special characters.
  • Keep all date columns in TEXT format.
  • Incorrect formats may cause upload validation failures.
